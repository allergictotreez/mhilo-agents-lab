mhilo agents

Every Claude Code session on your computer, drawn as a lab: who is working on what, where, and for how long.

How it works↓

Why

Ten sessions, one glance.

Run a few Claude Code sessions at once and the terminal stops telling you much. Which one is waiting on you? Which one has been on the same test for twenty minutes? Which agent is still out? The lab answers by putting everyone somewhere you can see them.

What you see · 6

  1. 01

    A wing per project

    tabs · counts

    Each project gets its own floor. Its tab counts the sessions that are busy, idle or stalled, so you know where to look before you switch.

  2. 02

    A pod per area of work

    pods · chalkboards

    A wing is split into the areas you work in: Search, Payments, Audio, whatever the project has. Each pod's chalkboard lists the work going on there now, and its lamp is on while someone is inside.

  3. 03

    A worker per session

    busy · idle

    Every session is a lab worker. Busy, it stands at its pod's bench. Idle, it walks back to a desk in the lobby and waits for you.

  4. 04

    Agents walk out to help

    subagents

    When a session sends out an agent, a new worker walks to the pod it is working in. When the agent finishes, it heads for the door.

  5. 05

    A card for every worker

    click a worker

    Title, model, effort, time on the task, tokens, cost and the tool in use right now. A session's card lists its agents too.

  6. 06

    Trouble is a color and a word

    stalled · error

    A session that goes quiet for fifteen minutes in the middle of a task turns red and says stalled. No sound, no pop-up.

How it works

Read on your computer, drawn in the browser.

  1. 1

    The collector

    A small Node process on your computer watches Claude Code's session list and the end of each transcript. It keeps names, tools, counts and times, and drops the rest.

  2. 2

    The snapshot

    It sends one short summary per project when something changes, and at least once a minute. The page says so if a project goes quiet for three.

  3. 3

    The lab

    This page draws the summary in 3D and asks for a new one every five seconds. It runs in any modern browser, on a phone too.

Privacy

Titles and times. Never your prompts.

What leaves your computer

  • Session titles and agent descriptions
  • Tool names, with a hint of up to 60 characters: a command's first words or a file's name
  • Token counts, cost and timestamps

What never does

  • Prompt text or replies
  • File contents
  • Paths outside the project folder
  • Keys, passwords or access tokens

The real lab is behind a password, and five wrong tries lock sign-in for fifteen minutes. Visitors see a demo at the top of this page instead: invented projects and simulated sessions, made up in their own browser.

Run it yourself

Your sessions, on your computer.

Free and open source under the MIT license. It runs on your computer and stays there: no account, and nothing is sent anywhere unless you host your own copy.

  1. 1

    Download it

    git clone https://github.com/allergictotreez/mhilo-agents-lab.git
  2. 2

    Start it

    cd mhilo-agents-lab npm start

    Needs Node.js 20 or newer and Claude Code. Built on macOS; Windows and Linux should work too.

  3. 3

    Open the lab

    http://127.0.0.1:8777

    Your sessions appear within a few seconds.
