# site/art/ — the optional art hook

Empty on purpose. The lab draws everything procedurally until the owner generates art (the prompts
are in `docs/art/prompts.md`; Higgsfield spends credits, so nothing here is generated by an agent).

When images exist, drop them in this folder and add `art.json` beside this file:

```json
{
  "floorTile": "art/floor-tile.webp",
  "floorTileSize": 4,
  "boards": { "tracks": "art/board-tracks.webp", "environments": "art/board-environments.webp" },
  "floor": "art/floor.webp",
  "backdrop": "art/backdrop.webp",
  "signs": { "tracks": "art/sign-tracks.webp", "environments": "art/sign-environments.webp" }
}
```

| Key | What it replaces | Shape |
|---|---|---|
| `floorTile` | the drawn tile floor of every area and the lobby (the aisles stay plain) | seamless, square, top-down; repeated every `floorTileSize` world units (default 4). Shown as made — make it dark |
| `boards.<area id>` | the drawn chalkboard under that area's sign | about 2.4:1 (1224 x 512, 2x: 2448 x 1024; the pod's board is 3.11 x 1.30 m), dark green with white chalk. The left 45% is washed board-green and carries the live list of what the area is working on in chalk, so keep the art's subject on the right |
| `floor` | the plain floor under the wing (areas and lobby) | top-down, any aspect; it is stretched over the wing's bounds |
| `backdrop` | the flat night background behind the floor | 16:9, fitted to the screen |
| `signs.<area id>` | the drawn sign over that area's bench | 16:3 (e.g. 1024 x 192, 2x: 2048 x 384) |

Rules the loader enforces (`site/lab/scene.mjs`, `loadArt`): paths must be `art/<name>.webp|png|jpg`;
a missing or broken file is skipped with a console warning and the procedural version stays. Any
key may be left out. No code changes are needed.

Budget (`docs/standards/performance.md`): at most 300 KB per image, WebP preferred, sized for the
2x screen and no larger.

`.htaccess` denies `*.md`, so this note is not served.
